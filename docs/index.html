Talaria

Campaign email & communication template generator that any brand can configure to its own store, products, and branding.

React 19 TypeScript Tauri 2 Tailwind v4 shadcn/ui picamatl PDF optimizer
GitHub Documentation

Features

A modern, secure web application for generating professional communication templates for retail and brand operations.

📧 Campaign Email Builder

Advanced HTML email builder with collapsible editor cards, live preview, PDF attachments, and drag-and-drop reordering.

🏷️ Brand-Agnostic Profiles

Configure company, store, products, and branding once — then generate campaigns for any brand with zero hardcoded assumptions.

📄 PDF Optimization

Attach PDFs and get automatic size reduction (~59% typical) via the picamatl Rust library — lossy compression, DPI downscaling, stream packing.

📬 Bulk Email Export

BCC batch generation with configurable batch sizing, ZIP packaging, and EML/EMLTPL download for Outlook and other clients.

🌗 16 Color Palettes

Light and dark mode with 8 palettes each (oklch), accessible out of the box with WCAG AA contrast ratios.

🖥️ Desktop App

Optional Tauri 2 desktop build for Windows, macOS, and Linux with native file system access and faster PDF optimization.
